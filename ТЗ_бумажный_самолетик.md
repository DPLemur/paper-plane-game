# Техническое задание: «Сложи самолётик»

## Общая идея
Веб-игра (браузер, HTML/CSS/JS), в которой игрок складывает бумажный
самолётик из виртуального листа тетрадной бумаги, а затем запускает его
в тесте на склоне, где виртуальный человечек бросает модель, и она летит
согласно рассчитанной «аэродинамике» полученной формы. Цель — собрать
модель, которая пролетит дальше всех.

## Технологический стек
- HTML + CSS + JavaScript (vanilla или React)
- Canvas (2D) для отрисовки листа и анимации полёта
- Без бэкенда: вся логика — на клиенте
- Опционально: localStorage для сохранения рекордов (в игре вне
  Claude-артефактов; внутри артефактов Claude — только in-memory)

## Модуль 1. Представление листа бумаги
- Лист — многоугольник: массив вершин (x, y) в двумерных координатах.
- Стартовая форма — прямоугольник (пропорции тетрадного листа, например
  A5 или половина A4).
- Каждая грань может стать линией сгиба.
- Хранить историю сгибов как стек операций (для отмены/повтора).

## Модуль 2. Механика сгибания
- Игрок кликает на угол (вершину) и тащит его мышкой к любой точке листа.
- При отпускании кнопки мыши:
  1. Строится линия сгиба — серединный перпендикуляр между исходным
     положением угла и точкой, куда его перетащили (классическая
     оригами-операция «сложить точку к точке»).
  2. Все вершины по одну сторону от линии сгиба отражаются
     (мат. отражение относительно прямой).
  3. Новая форма фиксируется как текущее состояние листа.
- Во время перетаскивания — визуальный предпросмотр линии сгиба и того,
  куда встанет уголок (полупрозрачным слоем), чтобы игрок видел результат
  до отпускания кнопки.
- Ограничение: сгибать можно только за существующие вершины (угол листа
  или угол, созданный предыдущим сгибом).

## Модуль 3. Переворот листа
- Кнопка «Перевернуть» — зеркально отражает текущую форму по вертикальной
  оси (имитация переворота листа на столе) и меняет активную сторону
  (лицо/изнанка), чтобы следующие сгибы шли с другой стороны.

## Модуль 4. Оценка аэродинамики (эвристика)
Считается после каждого сгиба или по кнопке «Проверить полёт». Не нужна
честная физика — упрощённая формула на основе геометрии финальной фигуры:

| Параметр | Как считать (примерно) | Влияние на дальность |
|---|---|---|
| Симметрия | Сравнить левую и правую половину контура относительно продольной оси | Чем симметричнее — тем дальше и стабильнее |
| Острота носа | Угол в самой передней точке фигуры | Острый нос — меньше сопротивление |
| Ширина крыльев | Максимальная ширина фигуры относительно длины | Слишком узко или слишком широко — хуже |
| Соотношение длина/ширина | Вытянутость формы | Оптимум даёт бонус к дальности |
| Распределение «массы» (площади бумаги) | Где сосредоточена площадь по длине | Смещение веса вперёд — устойчивость |

Формула сводит эти параметры к одному числу — «дальность полёта» (в
условных метрах), плюс коэффициент «виляния» (чем хуже симметрия, тем
сильнее самолётик рыскает в полёте).

## Модуль 5. Тест на склоне
- Отдельный экран/режим: сбоку стоит человечек на пригорке.
- Анимация: человечек делает бросок, самолётик летит по параболической
  траектории, длина и «дрожание» траектории зависят от чисел из Модуля 4.
- В конце — надпись с результатом в метрах и (опционально) сравнение с
  лучшим предыдущим результатом игрока.

## Модуль 6. UI/UX
- Основной экран: лист бумаги по центру, кнопки «Перевернуть»,
  «Отменить сгиб», «Тест на склоне», «Начать заново».
- Индикатор текущих параметров (можно скрыть до первого запуска теста —
  элемент интереса «получится или нет»).
- Счётчик попыток / лучший результат за сессию.

## Порядок реализации (предлагаемый)
1. Отрисовка листа и статичной формы на canvas.
2. Механика захвата угла и превью линии сгиба.
3. Математика отражения (сам сгиб) + фиксация формы.
4. Переворот листа.
5. Формулы аэродинамики на тестовых формах (прямоугольник, треугольник,
   классический самолётик) — калибровка чисел.
6. Анимация теста на склоне.
7. Полировка UI, счётчик попыток, мелкие эффекты (тень от сгиба, звук).

## Возможные усложнения (на будущее)
- Библиотека готовых схем классических самолётиков как подсказка.
- Мультиплеер/таблица лидеров.
- Более честная физика (учёт угла запуска, силы броска игроком).
